# 手机验证码 → 桌面灵动岛

目的：手机上收到验证码，桌面顶部那条灵动岛立刻弹出来，验证码已经复制好，直接 `Ctrl+V` 就能填。

## 一、电脑端（一次性）

1. 灵动岛 → 设置 → 「短信验证码」一行里，输入设备名（如「小米」）点 **新建密钥** —— 配置（接口地址 + 这台手机专属的**推送密钥** + 安卓 APK 下载链接）会自动进剪贴板。
2. 再下面一行 **「电脑端密钥」**：填这把「读取密钥」，电脑才收得到手机推来的验证码（只存在这台电脑的 `state.json` 里）。
3. 密钥分三类，`read` / 老 `hook` 存在服务器 `/www/wwwroot/island/data/hook.json`，设备密钥存在 `sms_devices` 表：
   - 每台手机一把**设备密钥**（`新建密钥` 时生成，创建接口只返回一次，本机存在 `settings.smsDevices` 里；列表里能看谁在用、推过多少条，可单独「撤销」立即失效或「删除」记录）
   - `hook` = 老的共用推送密钥（兼容旧 APK，会显示成「旧版共用密钥」，建议尽快换掉）
   - `read` = 读取密钥（电脑端填），用来**收**（SSE 订阅 / 历史列表）
   这样即使手机那台设备丢了、密钥被看到，也只能往你的岛推假验证码，读不到你已有的短信；读取密钥只在电脑上，别发到群里。

桌面端会一直连着 `https://chat.ccyyqq.com/island/api/sms/stream?token=<读取密钥>`，收到消息就：
- 把验证码写进剪贴板；
- 弹一条通知（验证码 123456 + 来源号码）；
- 9 秒后自动收回（鼠标移上去会停住）。

## 二、安卓：装 APK（全自动）

安装包：<https://qing.ccyyqq.com/island/update/QingToolsSMS.apk>（约 24 KB，v1.4 / versionCode 4，自己签名，不上架应用商店）

1. 手机浏览器打开上面的链接下载 → 点安装 → 允许「安装未知应用」。
2. 打开「Qing Tools 短信」→ 点 **从剪贴板粘贴配置**（在电脑上点「手机端配置」复制的那一整段文字，通过微信/QQ 发到手机再复制，直接粘即可，会自动抠出地址和密钥）；或者手动粘贴密钥 → **保存并开启** → 弹出短信权限时选「允许」。
   - 只想验证通道：点「发送一条测试」，桌面应该马上弹「验证码 123456」。
3. **后台常驻（v1.3 起必须做一次）**：点 **开启后台常驻** → 允许通知（通知栏会常驻一条「Qing Tools 短信转发」，**别划掉它**）→ 弹「忽略电池优化」时选允许。
   - 小米/红米再加三道保险：设置 → 应用设置 → 应用管理 → Qing Tools 短信 → **自启动**打开、**省电策略 = 无限制**；最近任务里给它**上锁**。
   - 原理：v1.2 只在 `onReceive` 里起了一个裸线程就返回，系统认为广播已处理完，会把后台进程冻结，HTTP 请求发不完 —— 表现就是「必须开着应用才转发」。v1.3 用 `goAsync()` 撑住这次广播，再加一个前台服务让进程一直活着，并每 60 秒扫一遍收件箱兜底（万一系统仍然拦了广播，也不会漏）。
   - v1.4：广播和轮询会各命中同一条短信，加了 **10 分钟正文去重**（`Dedupe.java`），同一条不会弹两次条；轮询的网络请求也挪到了工作线程，避免主线程卡顿。
4. 只转发含「验证码 / 校验码 / 动态码 / 口令 / code / otp」等关键词的短信（可在应用里勾「转发所有短信」取消过滤），普通聊天短信不会上传。

打包方式（源码在本目录）：`mobile\android\build.ps1`，用 Android SDK 的 aapt2 + javac + d8 + zipalign + apksigner，**不依赖 Gradle**。

## 三、iPhone：两种接法

iPhone 不允许第三方 App 读短信，但**快捷指令自带的「我收到符合以下条件的信息时」触发器可以把短信原文传进来**（就是动作「将变量 `短信原文` 设为 `输入快捷指令的信息`」）。所以 iPhone 也能做到全自动 —— 前提是那个触发器卡片**已经启用**：卡片是虚线、底下写着「配置"信息"启用此自动化」，就说明还没启用。

### 路线 1（推荐，全自动）：把「收到信息」触发器放进快捷指令

#### 第 1 步：先在电脑上给 iPhone 建一把密钥

Qing Tools → 设置 → 短信验证码 → 「手机密钥」输入 `iPhone` → **新建密钥**（配置会自动进电脑剪贴板，里面就有这把密钥）。

#### 第 2 步：iPhone 上新建快捷指令

「快捷指令」→ 右上角 **+** → 命名 `验证码到灵动岛`，加三个动作：

1. **我收到符合以下条件的信息时** → 条件填 `信息 包含 验证码`
   （想同时覆盖取件码/校验码，就填 `码`；想所有短信都发，就把条件删掉）
2. **将变量** `短信原文` **设为** `输入快捷指令的信息`
3. **获取 URL 内容**：
   - URL：`https://chat.ccyyqq.com/island/api/hook/sms?token=<你的手机密钥>`
   - 「显示更多」→ 方法 **POST** → 请求体 **JSON** → 两个字段：
     - `text` = 变量 `短信原文`
     - `from` = `iPhone`（随便写，会显示在岛上的副标题）
4. （可选）**显示通知**：「已发到灵动岛」

#### 第 3 步：把触发器启用

打开这个快捷指令，若触发器卡片是虚线 → 点它 → 「启用此自动化」；再把它设置里的「运行前询问」关掉。卡片变成实线就生效了。

#### 第 4 步：真机验证

让别人给你发一条 `【测试】您的验证码：123456` 的短信 → 桌面岛应自动弹「验证码 123456」。

> 注意：一个快捷指令只能有**一个**触发器。想同时保留「取件码 → 提醒事项」和「验证码 → 灵动岛」，就复制成两个快捷指令（两个自动化），互不影响。

#### 直接复用你已有的「提取取件码」快捷指令

可以，改 3 处就行：

1. 长按 `提取取件码` → **复制** → 改名 `验证码到灵动岛`（原快捷指令别动）；
2. 把条件 `信息 包含 取` 改成 `信息 包含 码`（否则验证码短信不会触发）；
3. 删掉 `匹配 取件码…` / `如果 匹配 没有值` / `停止执行此快捷指令` 这三个取件码专用动作，保留开头的 `收到信息时` + `将变量 短信原文 设为 输入快捷指令的信息`，末尾加上面第 3 个动作（获取 URL 内容 POST JSON）。

想一个快捷指令同时干两件事也可以：条件放宽成 `码`，中间保留 `匹配` + `如果 匹配 有值`（有值 → 添加提醒事项），最后一个动作无条件发 `短信原文` 到岛。

### 路线 2（兜底，手动）：剪贴板 + 轻点背面

如果不想开「收到信息」自动化（比如担心隐私或触发器不生效），就用手动方式：

1. **获取剪贴板**
2. **获取 URL 内容**：URL `https://chat.ccyyqq.com/island/api/hook/sms?token=<你的手机密钥>`，「显示更多」→ 方法 **POST** → 请求体 **JSON** → `text` = 剪贴板变量、`from` = `iPhone`
3. （可选）**显示通知**

（也可以用 GET：`…&text=` 后面接「URL 编码」过的剪贴板变量 —— **只编码剪贴板内容，别把整条 URL 丢进「URL 编码」**，否则 `https://` 会变成 `https%3A%2F%2F`。)

然后绑一个顺手的触发：

| 触发 | 设置路径 | 体验 |
|---|---|---|
| **轻点背面**（最推荐） | 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 选「发到灵动岛」 | 收到验证码 → 点键盘上方「从短信拷贝验证码」→ 敲两下手机背面 → 完成 |
| **操作按钮**（iPhone 15 Pro 及以后） | 设置 → 操作按钮 → 选「快捷指令」→ 选它 | 长按侧键即发 |
| **分享菜单** | 快捷指令详情里打开「在共享表单中显示」 | 信息里长按短信气泡 → 分享 → 发到灵动岛 |
| **桌面图标 / 锁屏小组件** | 长按桌面 → 添加小组件 → 快捷指令 | 点图标即发 |

> 为什么路线 2 还要手动：电脑端扫的是 **Windows 剪贴板**，iPhone 上复制的内容不会自动同步过来（通用剪贴板只对 Mac 生效）。

## 四、鸿蒙（HarmonyOS NEXT / ArkTS）

源码和完整操作说明在 [`harmony/README.md`](harmony/README.md)。

源码压缩包（约 13 KB，和本目录 `harmony/` 完全一致，改过就重传）：
<https://qing.ccyyqq.com/island/update/QingToolsSMS-harmony.zip>
备用：<https://qingtools.ccyyqq.com/download/QingToolsSMS-harmony.zip>

要点：

- 鸿蒙同样不让普通应用直接读短信：`RECEIVE_SMS` 和 `NOTIFICATION_CONTROLLER` 都是**受限权限（ACL）**，要在 AppGallery Connect 申请通过才能用；
- 所以默认走「**复制验证码 → 点一下应用/服务卡片**」的路线（零受限权限，一定能用），和 iPhone 的快捷指令一个思路；
- 申请到 ACL 后可以打开「自动监听通知」，把短信通知里的验证码自动转发（原理同安卓的 NotificationListener，包名 `com.ohos.mms`）；
- 服务端接口、密钥、限流规则和安卓/iOS 完全一样。

## 五、接口（自己接也行）

```bash
curl -X POST 'https://chat.ccyyqq.com/island/api/hook/sms?token=<设备密钥>' \
  -H 'Content-Type: application/json' \
  -d '{"from":"10690001","text":"您的验证码是 518204，2 分钟内有效"}'
# => {"ok":true,"id":"...","code":"518204","device":"小米"}
```

- 鉴权：`?token=` 或请求头 `X-Hook-Token`；token 可以是**设备密钥**（推荐）或老的共用 `hook` 密钥（记为「旧版共用密钥」）
- 其他端点：`GET /island/api/sms?token=<读取密钥>&limit=10`（最近几条）、`GET /island/api/sms/stream?token=<读取密钥>`（SSE）
- 设备管理（都要读取密钥）：`GET /island/api/sms/devices`、`POST /island/api/sms/devices`（body `{"name":"小米"}` → 返回一次 `token`）、`POST /island/api/sms/devices/<id>/revoke`、`POST /island/api/sms/devices/<id>/remove`
- 限流：同一台设备每分钟最多 20 条，超了返回 429
- 验证码抽取在服务端做（与桌面端同一套规则），也会返回在 `code` 字段里；`text` 里没有验证码时 `code` 为空串。
