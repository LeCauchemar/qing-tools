手机接入 · 安卓

装一个小 App，
验证码就自己走到电脑上

安卓这边不用绕：APK 装好、地址和密钥填一次，之后手机收到的验证码短信会自动发到你自己的服务器， 电脑上的岛弹一条通知、验证码直接进剪贴板。App 只读取短信，不碰通讯录和相册。

下载 APK 我用的是 iPhone

下载由又拍云 CDN 加速；本站镜像 /download/QingToolsSMS.apk。APK 没有上架应用商店，安装时系统会提示「未知来源」。

第 1 步电脑上

拿一份「手机端配置」

  • 打开岛 → 小工具 → 手机验证码同步：填个设备名（比如「小米 14」），点「新建密钥」。
  • 建好后这段配置会自动复制到剪贴板，里面是接口地址加这把手机专属的密钥；设备列表里点「复制」也能再来一次。
  • 密钥只对这台手机有效，列表里能单独「撤销」，撤销后这台手机立刻发不进来，别的设备不受影响。
第 2 步手机上

装 APK，粘贴配置

  • 在手机上打开本页，点上面的下载 APK。浏览器提示「这类文件可能会损害你的设备」时选仍要下载。
  • 点开安装包，允许「安装未知应用」→ 安装。它会申请读取短信权限，这是它唯一需要的敏感权限。
  • 打开 App，点「从剪贴板粘贴配置」——地址和密钥会一起填好。手填也行，接口地址默认就是 https://chat.ccyyqq.com/island/api/hook/sms。
  • 点「保存并测试」，状态栏出现「已连通」就说明电脑那边能收到了。
第 3 步别被系统杀掉

给后台留一条活路

  • App 用前台服务常驻（通知栏会有一条「正在监听短信」的常驻通知），这是安卓允许长期运行的正规方式，别把它划掉。
  • 小米 / Redmi：设置 → 应用设置 → 应用管理 → Qing Tools → 省电策略选「无限制」，并允许「自启动」。
  • OPPO / 一加 / realme：设置 → 电池 → 应用耗电管理 → Qing Tools → 允许后台运行、允许自启动。
  • 华为 / 荣耀：设置 → 应用 → 应用启动管理 → 关掉「自动管理」，手动勾上「自启动 / 关联启动 / 后台活动」。
  • 手机重启后 App 会自己恢复（有开机广播），不用手动打开。
第 4 步验证

发一条短信试试

  • 用另一台手机发一条带 6 位数字的短信。几秒内电脑上的岛会弹条，验证码已复制。
  • 没反应：先看手机上 App 的状态行有没有「最近转发」，再看电脑端那张卡片里这台手机的「最近上报」时间。
  • 默认只转发含「验证码 / 代码 / 口令」这类词的短信；App 里有个「全部转发」的开关，打开就什么都转（不建议，广告太多）。
  • 重复的短信会被去重，同一条不会推两次。
补充隐私

它读什么、传什么

  • 只在收到短信时读这一条；不读历史短信、不读通讯录、不读相册、不申请定位。
  • 转发走 HTTPS，落到你自己的服务器；服务端按电脑身份隔离，别人的手机推的东西不会出现在你的岛上。
  • 想彻底停掉：电脑端撤销密钥，或在手机上直接卸载——两者任一都立即生效。
  • 用 iPhone 的话看 iPhone 接入，那边不用装 App，用系统自带的快捷指令。
