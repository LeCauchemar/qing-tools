开发记录

十一天，六十多个版本，
一条缝长成了一个工作台

1.0 的时候它只会伸缩和显示未读；到 1.16.6，它替你收邮件、抽验证码、接手机短信、暂存文件、 在群里发一句就走，验证码还跟着账号在几台电脑之间跑。下面是中间每一步到底改了什么、为什么改。

11天（11-05 → 11-15）
100 MB安装包（砍过 21 MB）
7个页签
1.011-05

立骨架：先让它能装、能开、不崩

  • 选 Electron。透明无边框 + 置顶 + GPU 合成 + 托盘 + 开机自启 + NSIS，全都是一等能力；同样的「液态形变」用 WPF 做代价大得多。
  • 五种形态。空闲 178×34、快捷条、面板 576×448、通知条、拖放态；靠 CSS 变量 + data-state 切换，动画交给 GPU。
  • 点击穿透。窗口铺满屏宽但鼠标穿透，主进程 32 ms 轮询光标，命中岛矩形才收事件。第一版因为拿到旧 bounds，鼠标根本点不上去。
  • 能用的功能。邮件 IMAP 推送（验证码/链接自动变芯片）、备忘录、剪贴板、文件暂存、小纸条群聊（12 位匹配码进房）、托盘、开机自启、安装包 + 便携版。

把流程做顺，少一点手滑

  • 拖放分两区 —— 上半进文件、下半发小纸条，落点决定结果；列表行内出现 ➤ 可以直接把内容甩进聊天。
  • 切频道只是切频道，复制匹配码单独给一个 ⧉；岛右侧的数字只算小纸条未读。
  • 聊天图片点开进岛内遮罩，可放大、右键复制/另存，不再拉拉浏览器。

1.9.15 – 1.9.2211-06

  • 剪贴板图片「发送到小纸条」点了没反应：渲染层 fetch 自定义协议被跨域拦，改成主进程 IPC 取字节再拼 Blob。

  • SSE 会永久 CLOSED 不重连，加了 30 秒看门狗；验证码改成 keep 写入，能留在剪贴板历史里。

1.10.311-10

备忘录变成真正的富文本：图片长在文字中间

  • 粘贴不再另起一条。根因是编辑态用的是 <textarea>，塞不进图片，旧代码只能把图片存成一条新备忘录。改成 contenteditable 富文本后，图片留在光标处，条目还是那一条。
  • 插入要等异步。存图要几百毫秒，等回来时选区早没了 —— 先在光标处插一个零宽占位文本节点，图存好再把它换成图片，光标落在图下一行，可以接着写。
  • 粘贴跟着当前那条走。焦点不在编辑框里（比如停在上面的新建输入框、或刚点过别处）时，图片也会插回正在编辑 / 展开的那条，并回到上次的光标位置，不会再凭空多出一条。
  • 编辑时不重建 DOM。重渲染会把光标顶掉，所以正在编辑的富文本框直接跳过重建；停止输入 800ms 自动存一次，Ctrl+Enter 立即保存退出。
  • 图片尺寸。行是纵向 flex，不写 align-self: flex-start，小图会被拉成整行宽；现在小图保持原尺寸，大截图按 132px 高缩略，点开仍是全屏遮罩。
  • 桌面便签同样显示。钉到桌面的便利贴里，图片按原文位置显示（上限 240px 高、完整不裁切），在便签里继续打字、插图都会原样存回去。
1.10.411-10

编辑框里也有了右键菜单，粘贴不再跑到下面那条

  • 编辑框右键菜单。剪切 / 复制 / 粘贴 / 粘贴图片 / 全选，图片插在光标处；以前 Electron 里编辑框右键什么都不会弹。
  • 不会再丢字。重绘前先把编辑框里的内容落盘（flushLiveNote()），刚打的字不会被旧数据覆盖。
  • 条目不会在你手底下跳。编辑中把这一条钉在原来的位置，不因为自动保存更新了时间就重排 —— 以前看起来就像图片「跑到下面那条」。
  • 粘贴只认当前那条。编辑框里、展开的那条、上次光标所在的条目，优先级依次递减；都没有才新建。
  • 便签里的图。按完整比例显示（object-fit: contain，上限 240px），不再被裁成一条。
1.10.511-10

新建框里写的字和刚贴的图，合成同一条

  • 先打字再贴图，不会再被拆成两条。以前在顶部新建框里写了一半、再按 Ctrl+V，图被单独存成一条，字还留在框里，一保存又多一条。现在合成同一条：图接在文字下面一行，条目直接进入编辑态。
  • 结论按「这次在哪个框里按的」来判。新建框里有字就以新建框为准；新建框是空的，才退回正在编辑 / 展开的那条 —— 两条反馈看起来矛盾，其实是同一个判断没做对。
  • 右键「粘贴图片」同样生效。以前菜单一关就把粘贴目标清掉了，判断永远失效；现在先记下目标再关菜单，图和字照样合成一条。
  • 图片一律缩略图。正文里按行内缩略显示，点开是整屏遮罩看原图；钉到桌面的便签里按完整比例显示，不裁切。
1.10.611-10

通知条底部的进度线，收回到药丸里面

  • 线不再贴在药丸下沿。收到消息弹出来的那条通知，底部有一根 2px 的倒计时进度线，原来是从窗口左边缘拉到右边缘、紧贴圆角下沿，看上去像一条浮在桌面上的细线；现在左右各缩 18px、抬高 7px、圆头 3px，整根都在深色药丸里面。
  • 配色跟着主题走。进度用主题色混一点深色（82%），轨道只有 9% 的墨色 —— 深色主题不刺眼，浅色主题也不会消失。
  • 行为没变。点击通知条仍按类型打开邮箱 / 小纸条，验证码那类点一下复制；进度线只是把「还能停留多久」画清楚。
1.10.711-11

桌面便条：图片能点开看大图，纸也能拖着走、拉着改大小

  • 点图片看大图。便条里的截图以前只能看缩略图，现在点一下弹出一个独立的「看大图」窗口：滚轮以光标为中心缩放、按住拖动平移、双击回到适应大小、Esc 或 ✕ 关闭，窗口自己也能拖着标题栏移动。
  • 整张纸都能拖着走。以前只有顶部那一条（还被胶带挡住一半）能拖，现在纸边、留白、底部都能拖，正文区专门留给打字和选字。
  • 右下角能改大小。透明无边框窗口在 Windows 上没有系统缩放边框，所以自己做了右边、下边、右下角三条把手；拖完的尺寸会记住，下次打开还是这么大。
1.10.911-11

安装包改走又拍云 CDN，连不通再回自己服务器

  • 小工具里点「检查更新」下载的是 CDN。100 MB 的安装包不再从 chat.ccyyqq.com 走，改成先拉 qing.ccyyqq.com（又拍云）；服务器只负责发几百字节的 latest.json，带宽留给别的事。
  • 连不通会自动换地址。每个来源下完都算一遍 SHA-256 和 latest.json 对一遍，不一致或者网络错误就换下一个：CDN → 清单来源的服务器 → 服务器固定地址，三条都不行才报失败。
  • 官网的按钮也一样。页面加载时先探一下 CDN 的 latest.json，探不通就把三个下载按钮和「备用下载」对调，下面那行字会标成「已自动切到本站镜像」。
  • 清单仍然是服务器优先。又拍云会把 latest.json 缓存好几天，所以「有没有新版本」还是问自己服务器，发布即生效。
1.10.1111-11

提醒事项的日期时间看得见了，标题栏也不空着了

  • 原生 datetime-local 之前按浅色 scheme 画，深色面板上是黑字黑底 —— 现在 color-scheme 跟着主题走，两套主题都清清楚楚。
  • 日期框统一 26px 高、等宽数字，日历图标 hover 变亮，聚焦有强调色描边。
  • 删掉提醒卡下面那段长提示，空状态不再占地方。
  • 面板标题栏在时间右边补上「11月11日 周三 · 十月初三 · 11° 晴」，日期、农历/节日、天气一眼看全。
  • 通知条上的「刚刚」放大到 12.5px 并靠右对齐；小纸条的昵称、气泡正文（14.5px）、时间、系统提示统一调大一档。
1.11.011-13

有账号了：登录一次，换台电脑也是你

  • 服务端先落了整套账号后端：注册 / 登录 / 找回 / 注销、设备列表、单个会话撤销、退出全部设备；密码和恢复码都用 scrypt 存哈希，登录态是不透明 token（库里只存 SHA-256），所以「踢掉某一台」是真的立刻失效。
  • 桌面端设置页最上面多了一组「账号」：用户名 + 密码登录或注册，注册完强制显示恢复码并要求勾选确认才能继续；已登录时能看到这台电脑在内的所有设备、最后活跃时间，逐台移除。
  • token 用 Windows DPAPI（safeStorage）加密后存 account.json，关掉应用再开自动恢复登录；401 时自动清掉本地登录态并提示重新登录。
  • 找回密码用恢复码：换完密码旧码立即作废、当场给新码；注销要三重确认（用户名 + 密码 + 恢复码），注销后用户名永久保留、不会再放给别人。
  • 这一版只做账号本身，本地备忘录/待办等数据仍在「本地模式」；把它们归属到账号下（含换账号不串号的分区）是下一个里程碑。
1.12.011-13

Qing 事项、账号归属、频道跟着账号走

  • 备忘录和待办合成一个「Qing 事项」。输入框上方两个 chip 选类型：备忘录照旧；待办前面多一个圆圈，点一下打勾（会划掉并变淡）。小工具里那张待办卡整张撤掉，不再两边各记一份。
  • 待办建好自动钉在桌面右上角，到点看得见；钉住的条目（备忘录和剪贴板一样）删除按钮会置灰，先取消钉在桌面才能删 —— 免得「全部删除」误伤。
  • 登录后能把本机旧数据归到账号名下。设置页会出现一张归属卡片，写清「N 条备忘录 · N 个待办 · N 条提醒 · N 个纪念日」，可以「先导出备份」再「归到这个账号」；本机与账号的数据分区存放，登录退出各用各的，不会串号。
  • 频道跟着账号走。登录后本机已有的频道会逐个认领到账号名下（先到先得，别人认领过就跳过）；换台电脑登同一个账号，频道会自动加回来。
  • 设置页最下面多了「退出登录」，只退出这台电脑；同一账号在别的设备上仍然登录着。
1.12.111-14

归属之后，笔记里的图片也跟着搬过去

  • 之前把本机数据归到账号时只搬了文字，图片还留在本机目录里，结果账号分区里全是裂图（列表里只剩一个「图片」占位）。
  • 现在归属时会扫描每条笔记里的 [[img:文件]] 引用，把缺的图片从本机 note-images 复制到账号目录，重名跳过、路径做白名单校验，不会覆盖已有文件。
  • 已经在 1.12.0 归属过的机器，这次启动后打开那条笔记就能看到图（旧的裂图会重新解析到复制过来的文件）。
1.13.011-14

咻给好友：绑一个人，事项一键飞过去

  • 亲密好友：设置 → 亲密好友，填对方用户名发申请，对方同意就绑上，最多 3 个，随时能解除。
  • 小飞机：Qing 事项每行多了一个小飞机，点开选一个好友，「咻」一下飞走，服务端给对面复制一份独立事项。
  • 收的时候有心跳：对面收到时岛会横向抖一下，边缘散射一圈粉色光点，同时弹通知条、写进自己的 Qing 事项。
  • 复制是一份独立副本：你改你的、他改他的，互不影响；对方的完成状态你也看不到。
1.14.011-14

频道跟着账号走：换台电脑，群里还是你

  • 登录后加入的频道会记在账号上，换电脑登同一个账号，频道自己回来（先到先得认领，别人抢不走）
  • 消息带上发送者账号；同一个人开两台电脑，群里只算一个人、只占一票
  • @ 与拍一拍按人走：手机式的「u:账号」标记，两台设备同时收到
  • 投票踢人按人算，过半口径不变；被投的账号会被整体移出这个频道
  • 已读位置按人保存，一台电脑看过，另一台的红点也灭
1.15.011-14

待办的圈细回去了，清空不再误删，小纸条里能看见好友

  • 待办前面那个勾改回细圈：17px、1.2px 描边，完成时只是圈和勾变成强调色 —— 不再是点击后冒出一大块紫色方块。

1.15.111-14

Base64 能读图片了，几 MB 的数据也不会再把界面拖成 PPT

  • 开发小工具里「Base64」多了图片这条路：可以直接选一张图片转成 Base64，也可以把一大串 Base64 解回图片，解出来就在面板里预览。
  • 解码前先做体检：去掉换行空格、兼容 URL 安全的 -/_、剥掉 data:image/png;base64, 前缀，长度不对或者混进了别的字符会直接告诉你第几个字符有问题，而不是丢一句 atob 报错。
  • 最常见的「从聊天里复制了一半」会被认出来：开头像 PNG、但只有 20 字节时，会说「数据不完整，多半是从中间截断了」。
  • 不再把整段结果塞进文本框：超过 2 万字符只显示前 2 万（复制拿到的仍是完整内容），单次解码上限 8 MB，图片超过 6 MB 走文件选择而不是剪贴板。
  • 顺手的：解出来的图片可以「另存为」存到下载文件夹；直接把图片 Ctrl+V 粘进输入框，会自动走图片转 Base64。
1.15.211-14

超长 Base64 不再驻在输入框里，小工具终于不卡了

  • 以前把一段几 MB 的 Base64 粘进输入框后，那几百万字符一直留在 <textarea> 里，每次输入、滚动、切页签浏览器都要整段重排 —— 动画就变成了幻灯片。
  • 现在超过 20 万字符的内容会被直接搬进内存，输入框留空，只显示一行「已读入 2.51 MB（不放进输入框，避免卡顿）」+「复制 / 清空」两个按钮。
  • 解码 / 编码可以直接用内存里的这段数据，不用再把它塞回界面；实测 2.5 MB 的图片 Base64 解码 157 ms，输入框保持空白，连打 20 个字 0 ms。
  • 清空会同时清掉内存里的副本、预览图和结果，内存不会被一段贴过的大串长期占着。
1.16.011-14

Qing 事项跟着账号走：换台电脑，写完的东西还在

  • 每一项都带版本号落到云端：本机改完 0.5 秒后自动上传，另一台电脑 20 秒内自己长出来，包括待办的勾。
  • 删除也会同步：一边删掉，另一边下次同步就消失，不会「复活」。
  • 两台电脑同时改同一条：以最后写入的为准，被覆盖的那版留成一条「另一台设备改过的版本」，界面上有淡黄色标签，不丢字。
  • 笔记里的图片会自动传到又拍云，正文里只留一个云端 key，另一台电脑直接看到图，不再传 base64。
  • 设置页账号区多了一行「事项同步」：几条事项、上次同步是几秒前、有没有待上传的，都能看见，也可以手动「立即同步」。

1.16.411-15

验证码跟着账号走，不再跟着某台电脑

  • 之前短信通道是「每台电脑一个身份」：换台电脑登录同一个账号，之前建的手机密钥就看不见了，还得再粘一次主密钥重新绑一台「电脑」。
  • 现在登录账号后，手机密钥、短信记录、实时弹条全部按账号隔离：办公室和家里两台电脑登录同一账号，同一批手机的验证码两边同时收到。
  • 服务端 sms_devices / sms 加了 user_id，短信接口同时认账号登录态（Authorization: Bearer，SSE 用 ?token=）和未登录时的本机身份；已登录的客户端不会再被要求「绑定这台电脑」。
  • 没登录时仍按本机身份工作，老数据与旧 APK 都不受影响；但升级前建过的手机密钥属于旧的本机身份，登录账号后不会自动带过来 —— 在手机上重新粘一次新密钥（或撤销后重建）即可。
  • 界面也换了：登录后「服务器主密钥」那行自动收起，换成「账号同步」说明；手机密钥的文案改成「登录后跟着账号走」。
1.16.511-15

浅色主题下，下拉菜单不再是黑底黑字

  • 倒数日里「每月发薪日」的下拉展开后是一块黑底、只剩当前选中那一行能看见 —— 其它 31 个选项都在，只是黑底黑字。
  • 根因是 .select option 的背景写死成 #12141c，文字却跟着主题变量 --ink；浅色主题下 --ink 是近黑色，于是黑底叠黑字。

  • 同一套样式也用在提醒事项、倒数日的「每年 / 只这一次」上，一并修好。
1.16.611-15

好友申请会主动提醒，多行待办每行一个圆圈

  • 别人申请加你为好友后，以前只有去「设置 → 账号」才看得到。现在每 20 秒轮询一次：申请到达时岛会弹一条通知，点它直接跳到设置页；设置页签上也会亮一个红点，直到你处理掉。

  • 钉到桌面的便条也长出了同样的圆圈，点一下就能在桌面上勾掉，岛里和便条里两边同步。
