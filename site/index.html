功能

七个页签，都是你每天真会用的

没有花架子：每一项都对应一个高频动作，两下之内完成。

邮件：主动推，不用刷

IMAP 长连接实时推送，新邮件秒到。正文里的验证码识别成「⚡ 验证码 402913」，点一下进剪贴板；激活链接变成「↗ 打开链接」。支持 QQ / 163 / Gmail，微软邮箱内置账户授权引导。

Qing 事项：待办一行一个圆圈，还能钉到桌面

随手记一条，或者写成待办：每行一个圆圈，做完划线变灰，再点一次恢复。重要的「钉到桌面」——变成一张拟真便利贴，桌面上也能直接勾。取消钉住就收回岛里。

剪贴板：图文都留

文本和图片都记，固定住的关键条目连「全部删除」也删不掉。任何一条都能一键发到小纸条，或者直接拖给别的窗口。

中转站：拖一下就存

文件 / 文件夹拖到岛附近就进暂存箱，不用先开资源管理器。拖的是图片时会分成两半：左边存下，右边直接发小纸条。发出去的文件自动打包，也能一键上云拿链接。

小纸条：四个人以内

新建频道得到 12 位匹配码，发给朋友填码就进群，一个频道最多 4 台电脑，每人最多 2 个频道。换电脑输入旧昵称一键顶替，历史记录永久保留。

小工具：计时与安静

时/分/秒计时器到点提醒，岛旁边挂一个小圆环倒计时，跟 iPhone 灵动岛一样。免打扰一开，来消息只涨数字不弹条。还有 CPU / 内存 / 网速 / 电量的小圆点。

外观：深色 / 浅色 / 两种形态

深色玻璃和白色磨砂两套基调，主题色随便挑或者自己调。形态可选「灵动岛」悬浮，或「刘海」贴着屏幕上边只露一条。按住药丸还能左右拖动。

用法

学会四个动作就够用

快捷键

CtrlK命令面板：搜功能、开页面、起计时
CtrlShiftX划词速递：选中的文字直接进岛
CtrlShiftA截图：存进暂存箱并复制到剪贴板
CtrlAlt空格展开 / 收起
Esc一层层往回退

被别的软件占用时，程序会自动换一个能用的键位，命令面板里显示的就是真实生效的那个。

三个拖拽动作

  • 拖文件到顶部：直接进暂存箱，不发散到别的窗口
  • 拖图片到顶部：岛变两半，左边存、右边发小纸条
  • 从暂存箱拖出：拖到资源管理器 / 聊天窗口就是复制

右键藏着的东西

  • 聊天里的图片右键 →「查看大图」「添加到表情包」（群里共享）
  • 频道标签右键 → 重命名（只存本机），左键点 ⧉ 复制匹配码
  • 事项行右键 → 复制全文 / 发送到小纸条

问答

几个会被问到的问题

会不会拖慢电脑？占多少内存？

空闲时四个进程合计约 355 MB（Chromium 的固定开销，任务管理器里看起来会小一些），CPU 基本不动。剪贴板图片、聊天记录、邮件正文都做了按需加载和上限控制。已经砍掉 82 MB 的冗余运行时文件，安装包从 121 MB 降到 100 MB。

为什么提示「Windows 已保护你的电脑」？

因为没买代码签名证书（一年几千块，个人项目没必要）。点「更多信息 → 仍要运行」就行。安装包 SHA-256 会显示在下边区，可以自己核对。

邮箱怎么配？

设置 → 邮箱，选服务商后填邮箱地址和「授权码」（不是登录密码，QQ / 163 在网页版设置里开 IMAP 时生成）。微软邮箱（Outlook / Hotmail / Live）从 2024 年起停用了密码登录，程序里带 6 步指引，用账户授权（设备码）方式登录一次即可。

小纸条安全吗？谁能进我的频道？

只有拿到 12 位匹配码的人能进，码是随机大小写字母 + 数字，服务端只存密码学的哈希；每台设备有独立 token，退出或换机后旧设备立刻失效。消息存在自己的服务器上，不走第三方。

数据存在哪？换电脑会丢吗？

本机 %APPDATA%\DynamicIsland\，包括便签、剪贴板、暂存箱清单和邮箱配置（授权码和 OAuth token 都用 Windows DPAPI 加密）。小纸条的聊天记录存在服务器，换电脑用旧昵称接管就能继续看。

可以不装、直接用吗？

下载便携版，双击就能跑，不写注册表也不写开机启动。想要开机自启就装安装版。
